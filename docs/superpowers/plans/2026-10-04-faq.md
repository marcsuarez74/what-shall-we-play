# FAQ — Plan d'implémentation (v3.7.1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une page publique `/faq` — accordéon natif, 12 questions en 5 sections (contenu validé en maquette) — joignable depuis le menu du profil et l'accueil non connecté.

**Architecture:** Page statique server component (aucune session requise, zéro JS), liens dans `UserMenu` (connecté) et `AuthForm` (non connecté). Aucune nouvelle route API, aucun changement de schéma.

**Tech Stack:** Next.js App Router, `<details>/<summary>` natif, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-04-faq-design.md` (maquette validée : `.superpowers/brainstorm/24329-1791114664/content/maquette-faq.html` — le contenu des 12 Q/R y est en clair, c'est la source des textes)

## Global Constraints

- UI 100 % français.
- Page **publique** : aucun `getSessionUser`/redirect dans `app/faq/page.tsx` (pattern `/login`, `/register`).
- Contenu : les textes exacts de la maquette validée — **ne pas réécrire** les Q/R (elles ont été relues mot à mot par le client).
- Hooks E2E stables : `main` de la page, accordéons `aria-label="FAQ : {question}"` (le getByRole('button', name: …) des summaries reste l'interface).
- Palette noyer/crème/cuivre existante ; styles dans `app/globals.css` (bloc `.faq-*` en fin de fichier, comme `.imp-*`).

## Review Focus

1. **Visiteur non connecté sur /faq** — attendu : page complète, aucun redirect vers /login. → testé T1.
2. **Accordéon fermé par défaut sauf les 2 d'entrée** — « C'est quoi What Shall We Play ? » et « C'est quoi le verdict 😍🙂😐 ? » ouverts (`open`), les 10 autres fermés. → testé T1.
3. **Lien depuis le menu profil sans casser le menu existant** — le menu contient déjà Mon profil / Se déconnecter / Rapporter un bug ; « FAQ » s'insère sans modifier leurs hooks. → testé T2.
4. **Lien depuis l'écran non connecté** — visible sur `/login` ET `/register` (AuthForm partagé). → testé T2.

```ts
import { test, expect } from '@playwright/test';

test('la FAQ est publique, avec accordéons fonctionnels', async ({ page }) => {
  await page.goto('/faq');
  await expect(page.getByRole('heading', { name: 'FAQ' })).toBeVisible();
  // 2 accordéons ouverts par défaut, 10 fermés
  await expect(page.locator('details.faq[open]')).toHaveCount(2);
  await expect(page.locator('details.faq')).toHaveCount(12);
  // ouverture/fermeture
  const q = page.locator('details.faq summary').first();
  await q.click();
  // un clic sur le 1er (ouvert) le ferme → 1 ouvert restant
  await expect(page.locator('details.faq[open]')).toHaveCount(1);
});

test('le visiteur non connecté voit la FAQ sans redirect', async ({ browser }) => {
  const ctx = await browser.newContext(); // aucun cookie de session
  const page = await ctx.newPage();
  await page.goto('/faq');
  await expect(page).not.toHaveURL(/login/);
  await expect(page.getByRole('heading', { name: 'FAQ' })).toBeVisible();
});
```
